# 위치와 여행 기록 서비스 상세 분석

위치 기록 열람, 여행 일지 작성, 이동 영상 제작을 제공하는 7개 서비스와 공개 도구를 분석합니다. 분석 단위는 각 서비스의 목적, 입력, 탐색 방식, 사진 연결, 데이터 처리와 사용 조건입니다. 제품 순위나 Footprint Globe와의 비교·도입 제안은 포함하지 않습니다.

조사 기준일: **2026-10-06, 한국 시간**. 아래 모든 출처의 확인일은 이 날짜입니다. 빠르게 특징을 보려면 [핵심 정리](similar-services.md)를 읽으세요.

## 대상 선정과 판단 기준

앞서 제시한 후보 7개를 유지했습니다. Google Timeline 파일 열람 도구, 지속적인 위치 기록 관리 서비스, 여행 일지 앱, 활동 영상 도구를 각각 포함합니다. Dawarich 본 서비스와 별도 Timeline Visualizer는 같은 운영 주체의 서로 다른 사용 흐름이므로 별도 항목으로 다룹니다. 이를 독립된 업체 7곳이라는 의미로 해석하지 않습니다. Timeline Visualizer는 동명 도구와 혼동하지 않도록 **timelinevisualizer.org**로 한정합니다.

| 분석 항목 | 판단 기준 |
| --- | --- |
| 목적과 대상 | 공식 사용 흐름의 시작과 최종 결과를 기준으로 핵심 용도를 해석합니다. |
| 입력과 호환성 | 명시된 파일 형식·필드·제약만 기록합니다. 파일명이 같다는 이유로 모든 JSON 구조를 지원한다고 판단하지 않습니다. |
| 탐색과 경로 의미 | 날짜 선택, 지도·목록 연동, 경로 재생, 공백 처리와 방문 추론을 구분합니다. 3D 영상과 자유롭게 조작하는 지구본도 구분합니다. |
| 사진과 기록 단위 | 사진이 위치점·방문·게시물·활동 중 무엇에 연결되는지, 수동 첨부인지 외부 연동인지 확인합니다. |

| 사용 조건 | 가입, 무료·유료 기능, 설치와 외부 서비스 의존성을 확인합니다. 금액은 지역·결제 경로 차이를 피하기 위해 기재하지 않습니다. |
| 특징 해석 | 확인된 기능의 조합이 어떤 사용 목적을 지원하는지 설명합니다. 성능·정확도·만족도 우열은 평가하지 않습니다. |

**근거 수준:** 서비스별 표는 공식 사이트·도움말·제작자 README의 설명을 요약한 것입니다. 각 절의 ‘분석’은 그 근거에서 도출한 해석입니다. 로그인·결제·파일 업로드·실행 코드 감사·네트워크 검사는 수행하지 않았으므로 실제 동작과 전체 호환성을 검증한 결과는 아닙니다. 문서에 없는 기능은 ‘미확인’으로 두며 ‘미지원’으로 바꾸지 않습니다. 공식 설명끼리 충돌하면 구체적인 기능 문서, 적용 조건, 문서 갱신일을 함께 검토합니다.

## Dawarich

### 목적과 사용 흐름

Google Timeline 등 기존 위치 데이터를 가져오고 새 위치 기록도 계속 축적하는 위치 이력 관리 서비스입니다. 관리형 클라우드와 자체 서버 설치 방식을 제공합니다. 기록 수집 → 날짜·장소 탐색 → 여행·통계·사진을 통한 회고로 이어집니다. 장기간의 이력을 관리하는 제품을 분석하기 위해 선정했습니다. [제품 소개](https://dawarich.app/)

### 확인된 기능과 조건

| 항목 | 공식 자료에서 확인한 내용 |
| --- | --- |
| 입력 | Google Semantic Location History, Records.json, 휴대전화 내보내기, OwnTracks, GPX 등의 가져오기를 안내합니다. GPX의 기록된 트랙과 저장 장소를 구별하며 계획 경로인 rte는 제외한다고 설명합니다. [가져오기 문서](https://dawarich.app/docs/getting-started/import-existing-data/) |
| 탐색 | 시간 범위·장소 검색, 개별 점, 연결선, 히트맵, 방문 국가 표시 등 여러 지도 표현을 제공합니다. 장소와 방문을 수동으로 추가할 수 있습니다. [지도 기능](https://dawarich.app/interactive-map/) |
| 경로 의미 | 타임라인에서 기록 중단을 표시하고 자동 감지 방문에는 신뢰도를 표시한다고 설명합니다. 동일 페이지의 연결선 설명은 모든 위치점의 연속 경로를 강조하므로, 레이어별 공백 표현이 같다고 확정할 수는 없습니다. [지도 기능](https://dawarich.app/interactive-map/) |
| 사진 | Immich·PhotoPrism의 API로 사진 위치 메타데이터를 읽어 지도·여행에 연결합니다. 원본 사진은 복사·보관하지 않는다고 설명합니다. 이 주장은 해당 연동 기능의 설명입니다. [사진 연동](https://dawarich.app/integrations/) |
| 처리와 보존 | 본 서비스의 가져오기는 서버에 파일을 업로드하고 백그라운드에서 처리하는 흐름입니다. 자체 설치도 서버 기반 운영입니다. GPX·GeoJSON과 계정 데이터 내보내기를 안내합니다. [가져오기와 내보내기](https://dawarich.app/import-export/) |
| 사용 조건 | 관리형 서비스는 체험 후 구독하는 흐름이며 자체 설치는 무료로 안내합니다. 자체 설치에는 운영 환경과 유지관리 부담이 따릅니다. [제품 소개](https://dawarich.app/) |

### 분석

핵심은 **누적된 위치 기록을 검색·보완·재활용하는 것**입니다. 여러 입력을 모으고 방문을 수정하며 다시 내보내는 기능이 이 목적을 뒷받침합니다. 사진 기능은 별도 사진 관리 서비스와 연결하는 구조여서 해당 서비스의 준비와 접근 권한 설정이 사용 조건이 됩니다.

사진 연동 소개에는 클라우드 체험 유도 문구가 있지만 지도 기능 페이지는 사진 레이어를 자체 설치에서만 제공한다고 명시합니다. 따라서 **클라우드에서도 동일한 사진 연동을 쓸 수 있다고 판단하지 않습니다**. 가져오기 상태 표시 역시 기능 소개와 개발 문서의 설명이 달라 버전별 확인이 필요합니다. 밀집 지점 선택, 재방문의 내부 식별 방식, 실제 공백 임계값, 서버 삭제 후 백업 보존 기간은 이번 자료만으로 확정하지 않았습니다.

## Dawarich Timeline Visualizer

### 목적과 사용 흐름

Google Timeline 내보내기 파일을 달력·방문 목록·지도에서 열람하는 별도 웹 도구입니다. 파일 선택 → 연도·날짜 탐색 → 방문과 활동 확인이 중심입니다. 본 서비스에 가입하기 전에도 파일을 열람할 수 있는 흐름을 분석하기 위해 선정했습니다. [공식 도구](https://dawarich.app/tools/timeline-visualizer/)

### 확인된 기능과 조건

| 항목 | 공식 자료에서 확인한 내용 |
| --- | --- |
| 입력 | Records, Semantic, Semantic Segments, Settings, TimelineEdits, Location History를 나열하고 복수 파일 처리를 안내합니다. 모든 변형의 호환성은 독립 검증하지 않았습니다. |
| 탐색 | 달력 형태의 기록 분포, 날짜별 방문 목록, 활동 재생, 연도 필터와 방문 검색을 설명합니다. |
| 방문과 사진 | 원본 방문·활동을 열람하는 용도입니다. 수동 방문 작성, 사진 첨부·교체·삭제는 확인한 페이지에 구체적 설명이 없습니다. |
| 처리와 보존 | 기본 처리는 브라우저 내부라고 명시합니다. ‘Save to my Dawarich account’는 파일을 Dawarich Cloud로 업로드하는 별도 동작이라고 설명합니다. |
| 사용 조건 | 기본 도구는 무료·가입 불필요로 안내합니다. 계정 저장은 기본 열람과 구별합니다. |

표의 근거는 [도구 설명과 FAQ](https://dawarich.app/tools/timeline-visualizer/)입니다.

### 분석

핵심은 **큰 위치 이력을 하루 단위로 나누어 읽게 하는 것**입니다. 달력에서 시기를 고르고 목록에서 방문을 찾는 구조가 탐색의 중심입니다. 본 서비스의 영구 보관·사진 기능을 이 도구의 기능으로 옮겨 해석하면 안 됩니다.

‘데이터가 브라우저를 떠나지 않는다’는 일반 문구에는 계정 저장 예외가 있습니다. 지도 공급자 통신 여부, 긴 공백 연결 규칙, 동일 장소 재방문 선택과 대용량 성능은 실행 검증을 하지 않아 미확인입니다. 따라서 전체 네트워크 요청이 없거나 모든 내보내기 버전을 처리한다고 보증하지 않습니다.

## Google Location Visualizer

### 목적과 사용 흐름

alexkreidler가 공개한 Google Timeline 열람 프로젝트입니다. 제작자 README는 파일을 열고 날짜·시간을 고른 뒤 지도 마커나 시간 목록에서 위치를 찾는 기능을 설명합니다. 작은 범위의 위치 탐색 도구를 분석하기 위해 선정했습니다. [공식 저장소](https://github.com/alexkreidler/google-location-visualizer)

### 확인된 기능과 조건

| 항목 | 공식 자료에서 확인한 내용 |
| --- | --- |
| 입력 | Timeline.json 선택을 안내하고 새로운 Google 내보내기 형식을 대상으로 제작했다고 설명합니다. 지원 스키마·버전·용량 한도 목록은 제시되지 않습니다. |
| 탐색 | 날짜·시간 필터, 마커 상세 팝업, 시간 목록 선택 시 해당 위치로 이동하는 기능을 명시합니다. |
| 경로와 사진 | 경로 보간·공백 처리·방문 추론 규칙과 사진 편집 기능은 README에서 확인되지 않습니다. |
| 처리와 보존 | 사용자 데이터는 브라우저에서 처리하고 서버로 전송하지 않는다고 설명합니다. 영구 저장·복원 및 지도 요청의 범위는 별도 확인이 필요합니다. |
| 배포와 기술 | 공개 웹 주소를 연결하며 MapLibre GL JS, Shadcn UI, Tailwind CSS, Vite 등을 사용한다고 설명합니다. Apache-2.0 라이선스를 표시합니다. |

표의 근거는 [README](https://github.com/alexkreidler/google-location-visualizer)입니다. 코드 자체의 처리 동작과 라이선스 적용 범위를 감사한 결과는 아닙니다.

### 분석

**시간 목록과 지도 위치의 연결**이 가장 명확한 특징입니다. 특정 순간을 찾는 흐름은 문서에 드러나지만, 여행 기록 작성·사진 관리까지 제공하는 제품으로 볼 근거는 부족합니다. 무료 여부·상용 운영 지원·현재 배포본의 안정성은 저장소 공개 사실만으로 판단하지 않았습니다. 라이브러리 이름만으로 3D 지구본이나 외부 통신 부재도 추정하지 않습니다.

## Timeline Visualizer

### 목적과 사용 흐름

분석 대상은 **timelinevisualizer.org**입니다. 위치 기록의 영상화에 집중하는 도구로 선정했습니다. 파일 열기 → 영상 조절 → 재생·저장이 중심입니다. [공식 사이트](https://timelinevisualizer.org/)

### 확인된 기능과 조건

| 항목 | 공식 자료에서 확인한 내용 |
| --- | --- |
| 입력 | Records.json, timelineObjects, semanticSegments, 위치·시각을 포함한 좌표 배열을 나열합니다. rawSignals의 구체적 지원은 확인되지 않았습니다. |
| 경로 처리 | 잘못된 점 제거와 표시 밀도 축소를 설명합니다. 보간·공백 규칙은 미확인입니다. |
| 표현과 출력 | 이동 마커·날짜·거리를 표시합니다. 브라우저 코덱에 따라 MP4 또는 WebM을 저장합니다. |
| 사진 | 방문별 사진 첨부·보존 기능은 확인한 설명에 없습니다. |
| 처리와 보존 | 브라우저에서 처리하며 작업 데이터는 탭 종료 시 사라진다고 안내합니다. 기본 CARTO 지도 요청과 Privacy mode의 로컬 배경을 구별합니다. |
| 사용 조건 | 무료·가입 불필요로 안내합니다. |

표의 근거는 [동작 설명과 FAQ](https://timelinevisualizer.org/)입니다.

### 분석

핵심 결과물은 **편집된 이동 영상**입니다. 원본 기록 검색이나 보관보다 표시 범위를 고르고 재생 장면을 만드는 흐름이 강조됩니다. 점 제거와 표시 단순화가 있으므로 영상이 입력 기록을 손실 없이 재현한다고 판단하지 않습니다. 파일 업로드가 없다는 설명과 외부 지도 요청은 양립합니다. Privacy mode 역시 문서상 기능이며 네트워크 차단을 직접 검증한 것은 아닙니다. 동명의 다른 사이트·앱과 운영 주체가 같다고 가정하지 않았습니다.

| 항목 | 공식 자료에서 확인한 내용 |

### 분석

중심 단위는 **여행과 장소별 Step**입니다. 자동 수집한 경로에 사용자가 선택한 사진과 이야기를 더하면서 여행 일지를 구성합니다. 기록, 지인과의 공유, 인쇄물 제작이 하나의 흐름으로 이어지는 것이 특징입니다.

계정의 팔로워 승인 설정과 개별 여행 공개 범위는 서로 다릅니다. 비공개 계정이어도 특정 여행을 Everyone으로 설정하면 공개되며, 비밀 링크를 가진 사람도 설정에 따라 여행을 볼 수 있습니다. Only me는 다른 이용자의 열람 제한이며 서비스 운영자의 데이터 접근 부재를 뜻하지 않습니다. [공개 범위](https://support.polarsteps.com/hc/en-us/articles/24267891448850-Who-can-see-my-Polarsteps-account-and-trips), [개인정보 안내 3.5](https://www.polarsteps.com/legal/privacy?cky_preview=true)

사진별 용량·개수, 긴 기록 공백의 연결 기준, 밀집 지점과 동일 장소 재방문 선택, 삭제 후 백업 보존 기간은 확인한 자료만으로 확정하지 않았습니다. 배터리 효율과 추적 정확도에 관한 홍보 수치는 사용 환경을 검증하지 않아 평가 근거로 쓰지 않았습니다.

## FindPenguins

### 목적과 사용 흐름

여행 안에 장소별 게시물인 Footprint를 작성하는 여행 일지 서비스입니다. 가입 → Trip 생성 → 위치·날짜·제목이 있는 Footprint 작성 → 사진·영상 추가가 기본입니다. 자동 경로 기록은 선택적으로 켤 수 있습니다. 장소 단위의 게시 구조를 분석하기 위해 선정했습니다. [기본 사용법](https://support.findpenguins.com/hc/en-us/articles/360014103293-Learn-about-the-basics)

### 확인된 기능과 조건

| 항목 | 공식 자료에서 확인한 내용 |

### 분석

**장소별 게시물이 여행의 기본 구성 요소**입니다. 하루에 여러 방문 장소를 나눠 기록하고, 사진에 담긴 시간·위치를 과거 여행 작성에 활용하는 방식이 특징입니다. 게시물 수가 무제한이라는 설명과 게시물 하나의 첨부 한도는 별개입니다.

사진 한도는 2024-09-19 도움말의 20장과 2026-09-18 문서의 40장이 충돌합니다. 이 문서는 더 최근의 통합 한도 문서를 기준으로 설명하되, 앱에서 직접 확인한 수치로 취급하지 않습니다. [이전 사진 한도 문서](https://support.findpenguins.com/hc/en-us/articles/360014103393-How-many-photos-can-I-upload)

개인정보 정책에는 기본 공개값이 public으로 적혀 있습니다. 실제 가입 화면의 현재 기본값은 검증하지 않았으므로 구체적 공개 설정을 확인할 필요가 있습니다. 경로 보완의 정확도, 재방문 내부 식별, 삭제 후 보존 기간도 이번 문서 조사만으로 판정하지 않았습니다. [개인정보 정책](https://findpenguins.com/privacy)

## Relive

### 목적과 사용 흐름

달리기·자전거·등산 등 한 번의 야외 활동을 기록하고 3D 애니메이션으로 회고하는 서비스입니다. 직접 기록 또는 외부 활동 가져오기 → 활동 확인 → 영상 생성·편집 → 공유로 이어집니다. 활동 단위의 영상 제작을 분석하기 위해 선정했습니다. [공식 소개](https://www.relive.com/)

### 분석

중심 단위는 **개별 활동과 그 활동에서 만든 영상**입니다. GPS와 시간이 필수라는 입력 제약, 사진·음악·영상 속도 편집이 이 목적과 연결됩니다. 사진은 독립적인 장기 방문 앨범보다는 활동의 장면을 구성하는 요소로 설명됩니다.

소개 페이지의 ‘더 많은 사진은 Plus’라는 표현만 읽으면 무료 영상에도 사진이 들어간다고 오해할 수 있습니다. 구체적인 영상 도움말은 무료 영상의 사진 포함을 불가로 안내합니다. 또한 활동에 사진을 고르는 기능과 최종 영상에 넣는 기능은 다른 범위일 수 있으므로 무료 사진 수를 한 숫자로 합치지 않았습니다. [소개 FAQ](https://www.relive.com/explore), [영상 한도](https://support.relive.com/kb/guide/en/number-of-photos-and-or-videos-in-your-relive-video-HA9dqhYzNZ/Steps/3669589), [활동 사진 도움말](https://support.relive.com/kb/guide/en/why-are-some-of-my-photos-not-included-in-my-activity-Tg7hcqbC3h/Steps/3669569)

Google Timeline JSON 직접 지원, 긴 시간 공백의 표현, 재방문 구분, 네트워크와 삭제 동작은 미확인입니다. 개인정보 정책은 URL에 접근했으나 본문 재조회가 실패해 보존 기간 등의 근거로 사용하지 않았습니다. [정책 위치](https://www.relive.com/privacy)

## 근거 해석에서 남는 한계

공식 사이트·저장소의 접근 가능성과 기능 안내는 확인했지만 서비스의 종단 간 작동을 입증하지는 않습니다. 특히 파일 형식의 세부 호환성, 성능, 위치 정확도, 밀집 점 선택, 사진 교체·삭제, 외부 전송 부재는 실행 검증이 필요합니다. 미확인 항목은 해당 기능이 없다는 뜻이 아닙니다.

이번 분석에는 실제 Timeline·사진·원본 기반 샘플을 사용하지 않았습니다. 타 서비스 대비 우월성, 법률 준수, 시장 규모, 사용자의 만족도에 대한 홍보 문구는 평가 근거에서 제외했습니다. 서비스별 목적과 특징에 대한 해석만 제시하며 제품 선택 순위나 프로젝트 적용 판단은 유보합니다.
