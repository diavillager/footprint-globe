# 서울 발표 시연 데이터

`fully-synthetic.seoul-2026-10.json`은 실제 위치 기록을 사용하지 않고 작성한 공개 합성 데이터입니다. 관측 118개, 약 16KB로 구성했습니다. Google Timeline 앱 입력과 같은 `rawSignals[].position.LatLng/timestamp` 구조이며, 장소 API 응답이나 가짜 placeId를 파일에 넣지 않습니다.

## 사용 방법

1. [JSON 다운로드](https://github.com/diavillager/footprint-globe/raw/refs/heads/main/docs/demo/fully-synthetic.seoul-2026-10.json). 브라우저에 내용이 열리면 파일로 저장합니다.
2. 앱에서 JSON을 올리고 한국 시간 기준 2026-10-01–2026-10-07 전체 기간을 선택합니다.
3. 장소 조회 전송 안내를 확인하고 매핑을 허용합니다. 완료 후 **원본 경로**와 **장소별 보기**를 번갈아 선택합니다.
4. 광화문이나 조계사 주변을 확대하면 작은 관측점들이 장소로 묶이는 차이가 잘 보입니다. 전체 기간에서는 재방문한 장소에도 번호가 하나만 붙는지 확인합니다.

## 가상 일정

| 날짜(KST) | 순서 |
| --- | --- |
| 10월 1일 | 광화문 → 경복궁 → 북촌한옥마을 |
| 10월 2일 | 조계사 → 운현궁 → 창덕궁 |
| 10월 3일 | 창덕궁 → 창경궁 → 운현궁 |
| 10월 4일 | 광화문 → 조계사 → 운현궁 |
| 10월 5일 | 국립고궁박물관 → 경복궁 → 광화문 |
| 10월 6일 | 북촌한옥마을 → 창덕궁 → 창경궁 |
| 10월 7일 | 국립고궁박물관 → 조계사 → 광화문 |

매일 10시 시작, 장소마다 30분 체류하며 10분 간격의 관측 4개를 넣습니다. 그중 2개는 약 5–8m 차이를 둬 관측점 묶기를 보여줍니다. 장소 사이에는 8분 간격의 소수 경유점을 넣어 이동에 24–40분을 배정했습니다. 야간은 기록하지 않으며 날짜 사이 연결은 앱의 기존 공백 처리에 따릅니다.

조회 범위를 작게 유지하도록 청계천 북쪽의 약 2km 도심 권역으로 한정했습니다. 한강·청계천을 건너는 구간은 없고 다리를 생략한 강 횡단도 넣지 않았습니다. 경유점은 가상 이동의 개략적인 연결이며 실제 보행로·출입구·통행 가능 여부나 개장 일정을 보증하지 않습니다.

장소당 반복 관측과 다른 날의 재방문은 원본에 모두 남습니다. 의도한 방문 명소는 8곳이지만 중간 경유점도 주변 장소 후보와 대조하므로 **실제 매핑 결과는 정확히 8곳으로 고정되지 않습니다.** 사진 유무와 처리 시간은 Wikimedia 응답에 따라 달라지며 포인트 수가 API 요청 수와 같지는 않습니다. 자동 테스트의 가상 장소 응답 검증과 실서비스 조회 결과는 구별합니다.

## 생성과 검증

Node.js 24에서 `node scripts/write-seoul-demo.mjs`로 공개 JSON만 재생성합니다. 입력 파일이나 네트워크를 읽지 않으며 원본 위치 데이터에 접근하지 않습니다. 생성 소스는 `src/fixtures/seoul.ts`입니다. `npm run check`는 공개 파일과 생성 결과 일치, 실제 파서 수용, 7일·KST·순서·속도·위치 검사, 가상 응답을 통한 묶기·번호 통합과 원본 보존을 검증합니다.

2026-10-08 검증: 타입 검사·자동 테스트 283개·빌드 통과. 공개 영어 Wikipedia 지역 조회에서 명소 중심점 8곳 모두 해당 명소가 최근접 후보로 반환되는 것도 확인했습니다. 앱 전체의 실시간 사진 조회나 매핑 완료 시간까지 측정한 결과는 아닙니다.

공개 장소 중심점은 영어 Wikipedia의 해당 장소 좌표를 참고했으며 일정과 관측 변화는 직접 만들었습니다. 관광 권역 참고: [서울관광 공식 인사동·운현궁 코스](https://korean.visitseoul.net/palace/인사동-운현궁-코스/KON000653), [궁능유적본부 안내](https://royal.khs.go.kr/ROYAL/contents/R404000000.do). 실제 사용자의 방문 사실을 나타내지 않습니다.
