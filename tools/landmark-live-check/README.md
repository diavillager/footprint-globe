# 랜드마크 실제 연결의 로컬 합성 검증

일반 앱과 같은 `LocalPreview`를 사용하되 저장소의 네 합성 여행을 메모리에서 `File`로 생성해 입력합니다. 브라우저 확장의 로컬 파일 접근 권한 없이 파일 선택 이후 파서·지도·동의·실제 검색을 확인할 수 있습니다. 사용자 원본을 읽지 않으며 네트워크 업로드를 자동 실행하지 않습니다.

`.env.local`의 `VITE_MAPTILER_API_KEY`, `VITE_GEOAPIFY_API_KEY`와 정확한 허용 origin을 준비합니다. 키 값을 Git·문서·채팅에 기록하지 않습니다. 기존 서버 키를 코드가 자동으로 브라우저 키로 전환하지 않습니다.

```sh
npm run dev -- --port 4175 --strictPort
```

`http://127.0.0.1:4175/tools/landmark-live-check/`에서 여행 선택 → 합성 기록 불러오기 → 근접 관측 묶기 → 지도 지점 선택 → 파일별 동의 → 주변 후보 조회 순서로 확인합니다. **지도 로딩과 후보 조회는 실제 계정 사용량을 소비합니다.** 오류·회귀 검증에는 외부 요청 없는 `tests/landmark-smoke.cjs`를 먼저 사용합니다.

4175를 기존 비교 프리뷰가 사용 중이면 그 서버를 확인하고 중지한 후 실행합니다. 검증 후 기존 비교 프리뷰가 필요하면 앱 개발 서버를 종료하고 `node tools/landmark-preview/server.mjs`로 다시 실행합니다. 재시작하면 비교 프리뷰의 메모리 캐시·요청 횟수도 초기화되므로 이를 계정 무료 잔여량으로 해석하지 않습니다.

이 HTML은 개발 서버에서만 사용하는 별도 진입점입니다. 일반 앱 `/`에는 합성 입력 컨트롤이 없으며 기본 `npm run build`의 출력에도 이 진입점은 포함되지 않습니다. 실제 사용자 입력 검증은 사용자가 일반 앱에서 직접 수행합니다.

2026-10-07 실제 Chrome·MapTiler·Geoapify 연결: 네 합성 여행에서 한 묶음씩 명시적으로 조회해 오스트리아 10개, 프랑스 9개, 이탈리아 이동 구간 0개, 일본 3개 후보를 표시했습니다. 0개는 성공한 빈 결과입니다. 비교 프리뷰의 32개 지점과 같은 표본이 아니며 국가별 품질·실제 방문 검증이 아닙니다. 일본 결과는 다른 묶음으로 전환 후 돌아왔을 때 조회 1회 상태에서 재사용됐습니다.
