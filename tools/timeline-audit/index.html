파일 한 번으로 구조와 사용 범위를 확인하세요

Timeline JSON은 앱이 채택할 관측과 사용하지 못한 구조를, GPX는 트랙·구간과 좌표·시각의 유효성을 검사합니다. 원본을 직접 열어 누락을 찾으실 필요는 없습니다.

1. Timeline JSON 또는 GPX 선택

파일당 최대 64 MiB. 한 번에 한 파일을 검사합니다. GPX는 UTF-8의 표준 1.0·1.1 구조를 진단하며, 지도 표시나 Timeline과의 실제 비교는 수행하지 않습니다. KML은 지원하지 않습니다.

검사할 JSON 또는 GPX를 선택하세요.

2. 공유용 진단 보고서 저장

아래 보고서는 원본 값·파일명·임의 필드명을 포함하지 않습니다. 저장한 timeline-structure-report.txt 또는 gpx-structure-report.txt만 전달하시면 됩니다. 원본이나 가상 샘플은 보내지 않으셔도 됩니다.

파일은 이 탭과 로컬 작업 스레드의 메모리에서만 처리합니다. 외부 서비스 요청·자동 업로드·브라우저 저장소 저장이 없습니다. 지우기·새로고침·탭 종료 시 폐기합니다.

모든 항목을 탐색해도 모든 형식의 의미를 알 수 있는 것은 아닙니다. 미해석 구조와 보고서 상세 한도를 별도로 표시하며, 취소·실패는 완료로 표시하지 않습니다. 구조·건수 자체도 정보이므로 완전한 익명화를 보장하지 않습니다.
