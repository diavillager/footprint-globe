삼성 헬스 로컬 구조 진단

다운로드한 삼성 헬스 폴더에서 위치·시각 후보를 찾습니다. 결과는 건수와 고정 안내만 표시하며 파일명·건강 수치·실제 좌표·날짜는 표시하지 않습니다.

개인 데이터 다운로드로 받은 최상위 폴더를 선택하세요. JSON과 CSV를 하위 폴더까지 검사합니다. 원본은 변경하지 않습니다.

브라우저에서 “업로드” 확인창이 나올 수 있습니다. 선택 파일을 이 페이지에 제공하는 절차이며, 이 도구는 서버로 전송하지 않습니다. 선택창 자체에는 로컬 폴더명이 보일 수 있습니다.

진단 결과

아직 폴더를 선택하지 않았습니다.

인터넷·서버·로그인·설치 없이 Chrome/Edge에서 실행합니다. 파일 내용은 별도 처리 스레드에서 검사하고 완료·취소 시 해제합니다. 파일 저장·샘플 생성·경로 복원은 하지 않습니다.

한도: 2,000개 파일, 파일당 8 MiB, 누적 64 MiB, 1,000,000개 노드, 깊이 48. ZIP은 먼저 로컬에서 압축을 풀어 주세요. 알려진 구조만 검사하므로 후보가 없어도 위치 자료가 없다고 단정하지 않습니다.
