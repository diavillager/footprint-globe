# 랜드마크 API 로컬 비교

프로덕션 앱과 분리된 두 화면에서 동일한 가상 여행과 대표 지점을 비교합니다. 배포 프리뷰용 키·접근 설정이 준비되지 않아 localhost를 사용합니다. 비용 문제가 발생했다고 확인된 것은 아닙니다.

## 실행

Node.js 24에서 저장소 루트의 `.env.local`에 다음 키를 설정합니다. 키 값은 Git·채팅에 공유하지 않습니다.

```dotenv
MAPTILER_API_KEY=테스트용_키
GEOAPIFY_API_KEY=테스트용_키
```

```sh
node tools/landmark-preview/build.mjs
node tools/landmark-preview/server.mjs
```

- MapTiler: http://127.0.0.1:4175/maptiler/
- Geoapify: http://127.0.0.1:4175/geoapify/

여행 선택 → 가상 응답 시험 또는 실제 API 조회 → 비교 지점 선택 순서입니다. 가상 응답은 실제 명소가 아니며 화면 검증용입니다. 실제 API 오류가 발생하면 가상 결과로 대체하지 않습니다.

현재 키는 서버 시작 때 읽습니다. 키 변경 후 서버를 재시작해야 합니다. 서버는 루프백 주소에서만 수신하며, 키를 브라우저에 전달하지 않습니다. 키 제한은 로컬 서버 요청에 맞춰 설정해야 합니다. 요청에는 `Origin: http://127.0.0.1:4175`와 같은 주소의 Referer를 보냅니다. `PROVIDER_AUTH`는 제공자가 인증·접근을 거부한 상태이며 키 유효성, origin/referrer/IP 제한을 확인해야 합니다. 실제 API 응답 원문은 로그에 남기지 않습니다.

## 시험 범위

- 완전 합성 여행 네 개만 사용하며 실제 파일 입력은 제공하지 않습니다.
- 연속 관측을 첫 관측 기준 100m 안에서 묶습니다. 120분을 넘는 공백과 떠났다가 돌아온 기록은 별도 묶음입니다. 원본 관측은 삭제하지 않습니다.
- 10분 이상 머문 묶음 중 서로 120m 이상 떨어진 대표 지점을 최대 8개 선택합니다. 이는 시험용 선정이며 전체 방문을 대표한다고 보장하지 않습니다.
- 두 API는 같은 지점을 사용합니다. MapTiler는 일반 POI 역검색 최대 10개 중 300m 이내를 표시하고, Geoapify는 관광 명소·볼거리·박물관을 300m 반경에서 최대 10개 조회합니다. 범주와 순위 방식이 달라 결과 수만으로 품질을 비교할 수 없습니다.
- 가까운 명소는 방문 후보일 뿐 방문 확정이 아닙니다. 현재 말풍선은 첫 후보를 시험 표시합니다.
- 외부 지도 타일 없이 Natural Earth 개략 지도를 사용합니다. 확대 시 도로·건물·지명은 표시되지 않습니다. 선은 합성 관측의 연결이며 실제 이동 경로가 아닙니다.
- 실제 요청은 클릭할 때만 발생하고 서버 실행당 서비스별 최대 32회로 제한합니다. 성공 결과는 서버 메모리에 캐시하며 같은 조회는 재사용합니다. 오류 요청도 한도를 소비합니다. 재시작하면 캐시와 한도가 초기화되므로 반복 재시작에 주의합니다. 이 한도는 계정 무료 잔여량을 보장하지 않습니다.
- API에는 합성 대표 좌표와 검색 조건만 보냅니다. 전체 Timeline·여행 시각·개인 기록은 보내지 않습니다. 결과는 영구 저장하지 않습니다.
- 브라우저는 localhost에만 연결하며, 서버가 고정된 두 제공자 API에 요청합니다. 임의 좌표·주소를 받는 프록시가 아닙니다.

## 검증

`npm run typecheck`, `npm test`, 위 두 프리뷰 빌드를 실행합니다. 실험 로직 테스트는 `src/experiments/landmark.test.ts`에 있습니다. 키 없이도 가상 응답 시험을 할 수 있습니다. 지도·화면을 수정하면 빌드 후 브라우저를 새로고침합니다.

2026-10-07 검증: 두 프리뷰 빌드, 타입 검사, 전체 자동 테스트 131개 통과. 두 화면 모두 네 여행의 가상 응답과 말풍선을 확인했습니다. 키·개인 자료 경로는 HTTP 404, 잘못된 API 입력은 400, 출처 메타데이터 없는 API 요청은 403으로 차단했습니다. 기존 앱 회귀 빌드도 통과했으며 배포하지 않았습니다. MapLibre 번들 크기 경고는 남아 있습니다.

Geoapify는 IP 제한 설정 수정 후 실제 조회 32회가 모두 성공했습니다. 이전 인증 실패 시도는 2회이며 성공 집계에 포함하지 않습니다.

| 가상 여행 | 조회 지점 | 후보 합계 |
|---|---:|---:|
| 오스트리아 | 8 | 58 |
| 프랑스 | 8 | 46 |
| 이탈리아 | 8 | 58 |
| 일본 | 8 | 45 |

후보 합계는 지점 간 중복을 포함합니다. 방문한 랜드마크 수나 검색 정확도가 아닙니다. 작은 기념비·흉상과 계절 행사도 결과에 포함되었습니다. 현재 API 데이터가 과거 여행 날짜에 존재했던 명소임을 보장하지 않습니다.

공식 문서: [MapTiler Geocoding](https://docs.maptiler.com/cloud/api/geocoding/), [Geoapify Places](https://apidocs.geoapify.com/docs/places/), [Geoapify 키 제한](https://myprojects.geoapify.com/help/api-keys/).

## MapTiler 비교 결과 (2026-10-07)

MapTiler 테스트 키의 Allowed HTTP origins에 `127.0.0.1`을 추가하고 설정 반영 후 접근이 성공했습니다. MapTiler 설정에는 프로토콜과 포트를 제외합니다. Geoapify의 Allowed HTTP Origins에는 `http://127.0.0.1:4175`를 사용했습니다. 프로덕션 도메인 허용값은 유지합니다.

| 가상 여행 | 공통 조회 지점 | MapTiler 후보 | Geoapify 후보 |
|---|---:|---:|---:|
| 오스트리아 | 8 | 65 | 58 |
| 프랑스 | 8 | 64 | 46 |
| 이탈리아 | 8 | 69 | 58 |
| 일본 | 8 | 56 | 45 |

MapTiler는 브라우저 프리뷰에서 31곳을 조회했습니다. 앞선 인증 실패 1회가 서버 한도에 포함되어 일본 마지막 1곳은 같은 합성 지점·요청 생성·응답 처리 코드로 별도 단일 요청을 실행해 검증했습니다. 일본 프리뷰의 7곳 합계는 49개, 별도 검증한 마지막 지점은 7개입니다. 따라서 현재 서버 캐시에는 마지막 지점이 없으며 일본 화면은 PREVIEW_CAP을 표시합니다. 한도를 자동으로 늘리거나 자동 재시도하지 않습니다. 이 회차 MapTiler 성공 요청은 총 32회이며, 앞선 인증 실패 1회는 별도입니다.

MapTiler 결과에는 식당·옷가게·병원·편의점·역과 `-`처럼 식별에 도움이 되지 않는 이름도 포함됐습니다. 이는 일반 POI 검색 설정의 결과이지 MapTiler 전체 데이터에 관광지가 없다는 뜻이 아닙니다. Geoapify는 관광 관련 범주를 서버에서 제한하므로 이번 랜드마크 후보 검색 목적에는 우선 적용하기 쉽다는 판단입니다. 이 비교는 서로 다른 검색 방식의 적합성 확인이며 정확도 벤치마크가 아닙니다.

제안: 기존 지도는 MapTiler로 유지하고, 랜드마크 후보 조회에는 Geoapify를 사용합니다. 가장 가까운 후보를 자동으로 방문 장소로 확정하지 않고 사용자에게 후보 선택·해제 수단을 제공하는 방향이 적합합니다. 실제 사용자 좌표 전송 정책과 제품 적용은 아직 확정하지 않았습니다. 현재 프리뷰는 합성 데이터만 조회합니다.
