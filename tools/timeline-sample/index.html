Timeline 로컬 샘플 생성기

선택한 파일은 이 브라우저 탭에서만 처리됩니다. 네트워크 요청, 분석 서비스, 저장소 저장, 원본 내용 미리보기는 없습니다.

파일을 선택하면 자동으로 처리합니다. 원본은 변경되지 않습니다.

처리 결과 
아직 파일을 선택하지 않았습니다.

좌표는 원본 모양과 무관한 가상 좌표로 대체됩니다. 같은 좌표는 같은 가상 좌표에 연결됩니다. 시각은 공통 간격으로 옮기며, 시간대는 UTC로 바꿉니다.

샘플은 최대 9개 기록, 경로 배열당 24개 지점, 64 KiB로 제한합니다. 알 수 없는 필드가 있는 기록은 통째로 제외합니다. 방문과 이동을 모두 안전하게 포함할 수 없으면 저장할 수 없습니다.

지원하는 기록 배열 옆의 추가 최상위 필드는 샘플에서 제외합니다. 제외한 필드의 이름·내용은 표시하지 않고 개수와 이유만 알립니다.

최상위 형식을 인식하지 못하면 ‘구조 진단 v1’이 표시됩니다. 알려진 필드의 존재·자료형·집계만 포함하므로 원본을 열어 복사할 필요가 없습니다.

필드 구조, 기록 간 시간차·체류 기간은 남습니다. 공유 전 README의 확인 목록을 직접 확인하세요. 완전한 익명성을 보장하는 도구는 아닙니다.
