# 실제 기록을 위한 로컬 연결 미리보기

상태: 사용자가 미리보기 구현과 spec 작성을 승인했다. 제품 전체의 경로 추정·표시 정책 확정이 아니라 실제 기록을 직접 보며 비교하는 실험 도구다.

## 목적과 근거

[PRD](../docs/PRD.md), [공통 기반](2026-10-06-001-mvp-foundation.md)을 따른다. 가상 샘플은 좌표와 거리·모양이 바뀌고 9개로 축소되므로 실제 관측 밀도에 맞는 표시 정책을 확정할 근거로 쓰지 않는다. 사용자는 공백 때문에 흐름을 끊지 않는 발자취를 원한다. 따라서 유효 관측을 모두 연결한 실선과, 연결은 유지하되 긴 공백을 점선으로 표시한 결과를 비교한다.

## 범위와 입력

- 이번 미리보기는 최상위 rawSignals 배열만 처리한다. semanticSegments/timelineObjects가 함께 있거나 다른 형식이면 고정 오류로 중단한다. 모든 Timeline 버전 지원을 주장하지 않는다.
- 실험 도구 한도: 파일 64 MiB, 원시 신호 100,000개. MVP 전체의 최종 한도를 확정하지 않는다.
- position.LatLng 또는 position.latLng 중 하나의 좌표 문자열과 ISO 시각을 검사한다. 위도 ±90, 경도 ±180, geo: 또는 도 기호 표현을 지원하며 0 좌표를 보존한다.
- 시각의 달력 유효성·UTC 오프셋·최대 9자리 소수초를 검사하고 실제 시점 기준으로 정렬한다. 소수초 정렬은 BigInt로 비교하며 같은 시각은 원래 순서를 유지한다.
- 위치 외 신호와 잘못된 위치는 제외하고 각각 건수만 안내한다. 추가 속성은 정규화 결과에 복사하지 않는다. 앱용 추출기는 알 수 없는 속성 자체만을 이유로 정상 좌표·시각을 제외하지 않는다. 샘플 생성기의 엄격한 치환·제외 정책은 그대로 유지한다.
- 실제 파일은 사용자가 브라우저에서 직접 선택한다. 에이전트는 읽지 않는다. 표시 원본에는 가상화나 샘플 축소를 적용하지 않는다.

## 출력과 연결

파서 출력은 기존 TimelineData의 observations이며 recordedVisits/recordedPaths는 비어 있다. 새 파일마다 새 데이터셋 ID를 부여하고, 관측 ID는 정렬 전에 부여해 정렬·표시 변경 중 유지한다.

유효 관측 N개는 이웃 연결 N−1개를 가진다. 공백, 먼 거리, 같은 좌표, 같은 시각을 이유로 관측을 자동 삭제하지 않는다. 잘못된 기록이 제외되면 앞뒤의 유효 관측을 연결한다는 사실을 화면에 알린다. 연결은 실제 기록 경로나 도로 예측이 아니다.

- 모두 실선: 전체 연결을 같은 실선으로 표시
- 긴 공백은 점선: 사용자가 입력한 분 단위 기준을 초과한 연결만 주황 점선으로 표시. 연결 개수는 동일
- 최초 시험 기준은 60분이며 0–5,256,000분 사이에서 조절. 정확도 기준이나 제품 정책으로 확정하지 않음
- 지구 표면의 짧은 원호로 표시. 대척점은 가능한 원호 중 결정적인 하나를 택하며 실제 경로 의미를 부여하지 않음. 날짜 변경선에서 지구를 잘못 한 바퀴 돌지 않음
- 확대·축소·회전과 처음 관측 위치로 돌아가기 제공. 겹치는 점과 지구 뒤편의 점은 숨겨지거나 겹쳐 보일 수 있음
- 관측점은 화면 기준 약 3픽셀 지름의 원으로 표시하며 확대할 때 점 자체는 커지지 않음
- 버튼과 휠·핀치의 확대 범위는 동일하게 지구 반지름 대비 고도 0.015–4로 제한하여 카메라가 관측점·연결선 층 내부로 들어가지 않게 함

지구본은 포함된 공개 육지 윤곽을 사용하며 외부 지도·폰트·분석 요청을 하지 않는다. 표시용 보간은 원본에 추가 관측을 만들지 않는다. 관측점은 샘플링하지 않고 WebGL Points/LineSegments로 묶어 그린다. 표시 정점 2,000,000개 한도를 초과하면 지도를 생략하고 고정 경고를 표시한다. 집계는 유지하며 조용히 일부 경로만 그리지 않는다.

## 분포와 개인정보

전체 유효 관측의 이웃 쌍에 대해 시간차와 지표면 최단 거리의 구간별 건수, 중앙값, 90백분위와 최대값을 표시한다. 백분위는 정렬한 값의 인접 순위 사이를 선형 보간하며 짝수 건수의 중앙값은 가운데 두 값의 평균이다. 거리는 실제 이동 거리·도로 길이가 아니다. 소수초 정렬과 달리 집계는 부동소수점 밀리초 정밀도다. 연결이 없으면 통계는 해당 없음으로 표시한다.

입력 읽기·파싱은 Web Worker에서 수행한다. 파일 재선택·취소·지우기·종료 시 기존 worker를 중단하고 이전 결과가 다시 표시되지 않게 한다. WebGL 자원도 제거 시 해제한다. 원본 파일명은 파일 선택 후 지우며 원본 속성·값·오류 원문을 로그나 진단에 출력하지 않는다. 예외는 고정 코드로 처리한다. localStorage/IndexedDB·서버 저장·자동 전송·진단 내보내기는 없다.

배포용 앱 CSP는 connect-src 'none'으로 연결을 차단한다. 코드·worker·배경은 로컬 서버에서 제공하며 외부 자원은 불러오지 않는다. 개발 모드만 로컬 자동 새로고침 연결과 개발용 인라인 초기화 스크립트를 허용한다. 설치 시 npm 패키지를 다운로드하는 것과 사용자 파일 처리를 구별한다.

## 검증

- 완전 합성 위치로 파싱·좌표/시각 유효성·정확한 정렬·재방문·긴 공백·미지원 입력·제외 건수 확인
- 알려진 두 좌표 간 거리, 날짜 변경선/대척점 보간, 분포 구간과 경계 확인
- 10,123개 합성 관측이 10,122개 연결로 유지됨을 확인
- 개발/배포 브라우저에서 파일 선택 → 두 표시 모드 → 기준 조정 → 잘못된 입력 복구 → 지우기, 외부 요청·민감한 canary 로그·저장소 검사
- 실제 호환성과 화면의 유용성은 사용자가 로컬에서 확인. 원본 화면 캡처를 요구하지 않고 표시 방식에 대한 피드백을 받음

## 후속 결정

실제 데이터로 본 실선/점선의 선호, 점선 시험 기준의 적절성, 추가 표시 조정은 사용자 확인 후 결정한다. 방문 지정·사진 UI, 도로 맵 매칭, 추가 입력 형식은 이번 범위에 포함하지 않는다.
