# 화면·방문·사진 분리 개발

상태: 2026-10-06 사용자가 이 브랜치에서 구현·검증·수정별 커밋·푸시 및 전체 완료 후 PR 생성을 승인했다. 병합과 브랜치·워크트리 정리는 승인하지 않았다. 미확정 정책에 의존하는 구현은 답변 전 진행하지 않는다.

## 구현 중 확정·보류 사항

- 날짜·시각은 UTC와 한국 시간(Asia/Seoul) 사이 전환을 지원한다. 표시 전환으로 원본 시각·관측 순서를 바꾸지 않는다.
- 사진 지원 형식·개수·용량 정책은 사용자가 후속 결정으로 보류했다. 사진 구현과 같은 관측의 반복 방문 지정 정책은 미확정이다.
- 사용자는 전 세계 국가·지역·도시의 이름과 상세 경계를 확대 단계별로 표시하도록 요구했다. 외부 지도 서비스 검토와 별도 지도 spec 작성을 승인했으며 서비스 도입·실제 기록 기반 외부 요청은 아직 승인하지 않았다. 기존의 상세 지도 제외 문구는 이 최신 요구사항으로 대체한다.
- 최종 연결 표시 정책과 추가 브라우저 지원은 아직 확정되지 않았다. 기존 시험 UI와 Edge 검증을 유지하는 것은 이 정책들의 확정이나 추가 지원 보장을 뜻하지 않는다.

## 근접 표시 수정 진행

표시 층 기준 확대·카메라 near plane·회전 속도를 조절하고, 개별 연결은 근처 원점을 사용해 Float32 좌표 정밀도 손실을 줄인다. 커서 방향 확대와 회전 관성으로 선택 지점이 근접 화면에서 벗어나지 않도록 제어한다. 동일 좌표의 길이가 0인 연결은 그대로 유지한다. 합성 1m 간격·중복·장거리 검증을 추가하며 실제 기록에서의 유용성은 사용자 로컬 확인이 남아 있다.

## 범위와 구현 순서

1. 가까운 관측점의 선택·구분과 근접 확대를 개선한다. 단순히 카메라 제한만 풀지 않고 배경·선·점 높이, 카메라 잘림, 화면상 점 크기와 정밀도를 함께 검증한다.
2. 관측 선택 및 방문 지정 UI를 만든다. 겹친 관측은 목록 등으로 각각 선택할 수 있게 하고 같은 좌표의 다른 시점 기록을 하나로 합치지 않는다.
3. 방문에 세션 내 로컬 사진을 연결·미리보기·제거·교체하고 관련 자원을 정리한다.
4. 데이터 PR의 결과를 공통 진입점으로 반영해 파일 선택부터 방문·사진까지 통합 검증한다.

사용자 위치 전송, 온라인 지도 요청, 자동 방문·체류 추론, 도로 예측, 사진 EXIF 자동 배치, 영구 저장·복원, 로그인·공유는 현재 구현에서 제외한다. 국가·지역·도시 이름과 상세 경계는 최신 사용자 요구사항이며 [상세 지도 명세](2026-10-06-005-detailed-map.md)에서 서비스·전송 정책을 결정한 후 구현한다. 현재 배경으로 가능한 근접 표시 개선과 상세 지도 도입을 구별한다.

## 입력·출력과 책임

- 공통 `ParseResult`를 읽고 성공 시 TimelineData를 표시한다. 실패는 고정 코드, 부분 실패는 집계로 안내한다. 원본 메타데이터를 UI 오류나 로그에 복사하지 않는다.
- 독립 합성 결과와 `syntheticParser`로 화면 상태를 개발할 수 있다. 실제 파일 선택에는 실제 `parseTimeline`을 worker를 통해 연결한다.
- 화면 측이 File 선택·읽기·크기 검사, 데이터셋 ID 발급, worker 생성·취소·종료·이전 응답 무시를 책임진다. 새 데이터셋 선택 시 이전 방문·사진 상태를 섞지 않는다.
- TimelineData는 읽기 전용으로 소비한다. 관측의 정확한 파서 정렬 순서를 유지한다. 화면용 단순화·묶기·선택용 자료와 원본 관측을 구별한다.
- ManualVisit은 별도 방문 ID·데이터셋 ID·관측점 ID로 연결한다. PhotoAttachment는 데이터셋 ID·방문 ID를 참조한다. 좌표·마커 순서·배열 인덱스를 방문 identity로 사용하지 않는다.
- 같은 좌표 재방문에 붙인 사진이 서로 섞이지 않게 한다. 같은 관측을 반복해서 방문으로 지정할 때의 동작은 UI 구현 전에 명시하고, 사용자의 의도 없이 기존 사진을 덮어쓰지 않는다.

## 연결과 근접 표시

현재 미리보기는 모든 유효 관측 N개에 N−1개의 시간순 연결을 유지한다. 긴 시간차만으로 연결을 끊거나 관측을 삭제하지 않는다. 실선/긴 공백 점선 비교와 조절 가능한 시험값은 유지하되 최종 표시 정책으로 확정하지 않는다. 원본이 명시한 경로와 관측 사이의 연결을 같은 의미로 표시하지 않는다.

점과 선 끝은 같은 3차원 위치에 있어야 한다. 확대·회전해도 따로 움직이지 않아야 하며 과도한 확대에서 카메라가 표시 층을 통과하지 않게 한다. 동일 좌표는 확대해도 분리된 선이 생기지 않는다는 사실을 안내한다. 짧은 거리를 보여주기 위해 실제 좌표를 벌리거나 가짜 경로를 만들지 않는다.

사용자는 30분 초과 17개 연결에서도 점선이 보이지 않고 개별 대상으로 이동하면 점만 약간 움직인다고 확인했다. 근접 간격에 비해 최대 확대가 부족할 가능성을 인계하며 원인 확정이나 해결 완료로 기록하지 않는다. 구현자는 합성 근접·중복·장거리 사례로 검증하고 실제 유용성은 사용자 로컬 피드백으로 확인한다.

## 사진·실패·자원 정리

사진은 사용자가 직접 선택하며 서버 전송 없이 Object URL로 보여준다. 영구 저장은 없으며 새로고침·탭 종료 후 복원하지 않는 현재 정책을 안내한다. 사진 추가 실패나 디코딩 실패는 안전한 메시지로 안내하고 기존 정상 사진을 임의로 지우지 않는다.

사진 제거·교체, 방문 제거 기능이 있는 경우 해당 방문 제거, 데이터셋 교체·기록 지우기·컴포넌트 종료 시 더 이상 쓰지 않는 URL을 revoke한다. 개발 모드의 재마운트에서도 중복 생성·잘못된 해제가 없는지 확인한다. 파일명·EXIF·원본 오류를 로그·진단에 노출하지 않는다.

파일 읽기 실패·크기 초과·빠른 파일 재선택·취소·worker 실패·WebGL 불가 시 상태와 자원이 일관되어야 한다. 미지원 사진 형식·사진 용량/개수 제한은 아래 결정 항목을 따른다.

## 구현 전 결정이 필요한 사항

- 날짜·시각 표시 시간대는 위의 UTC·한국 시간 전환 결정 적용
- 사진 형식·개수·용량 제한 및 같은 관측의 반복 방문 지정 동작
- 최종 연결 표시 정책과 점선 기준. 결정 전에는 기존 시험용 비교 UI를 유지
- 추가 브라우저 지원 범위와 상세 지도 서비스·자료·전송 정책(별도 명세)

결정이 필요한 기능만 보류하고, 독립적인 렌더링·선택·자원 관리 검증은 진행할 수 있다. 명세 작성이 위 정책의 승인이나 새 기능 범위의 자동 확정을 뜻하지 않는다.
